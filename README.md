# 🔍 名探偵！かずのひみつ

小学5年生 算数「整数の性質」（偶数・奇数／倍数／約数／公倍数／公約数）の
導入〜まとめで使える、**探偵ゲーム形式の学習 Web アプリ**です。

「ヒント（手がかりカード）」を頼りに数表から「ひみつの数」を絞り込む謎解きを軸に、
単元の進み（フェーズ）に合わせて使えるヒントの種類と数のはんいが増えていきます。

- **フロントエンド**：HTML / CSS / JavaScript（GAS の HTML Service で配信）
- **バックエンド**：Google Apps Script
- **データ保存**：Google スプレッドシート（作問データ・グループ対抗スコア・進捗）
- スマホ・タブレットのブラウザに対応したレスポンシブ設計

## 画面と機能（MVP 優先度順）

| # | 画面 | 内容 |
|---|------|------|
| 1 | **ゲーム画面**（ひみつの数当て） | 数表（1〜50 / 1〜100）。手がかりカードを1つずつ提示するたびに、合わない数がグレーアウト＋取り消し線で消えていく。候補が1つになったら正解演出。絞りきれないフェーズ（偶数・奇数のみ等）は「のこりからタップして当てる」モードに自動で切り替わります。 |
| 2 | **てがかり図鑑・ランク** | 解禁済みカテゴリの一覧（未習得は🔒表示）、探偵ランクとバッジの進捗。フェーズ6で「名探偵 認定試験」を解禁。 |
| 3 | **ハイライトモード** | 2数 A・B の倍数（または約数）を色分けして数表に重ね、公倍数（公約数）を強調表示。最小公倍数・最大公約数を問う設問つき。フェーズ切替で 50⇄100 に変わる瞬間に「LEVEL UP！」演出。 |
| 4 | **作問モード** | 児童が「ひみつの数」と 2〜4個のヒントを組み立てて出題。追加のたびに「候補は◯個」とリアルタイム表示。みんなの問題ギャラリーに保存し、他の児童が挑戦可能。 |
| 5 | **グループ対抗** | 教員（出題班）がスクリーンに手がかりを1つずつ提示。回答班は各端末の数表を操作。正解の早さ・使用ヒント数でスコア加算し、スコアボードにランキング表示。 |

### 手がかりカードの色分け（依頼どおり）

| カテゴリ | 色 | 解禁フェーズ |
|---------|----|------------|
| 偶数・奇数 | 🔵 青 | 1 |
| 倍数 | 🟢 緑 | 2 |
| 約数 | 🔴 赤 | 3 |
| 公倍数 | 🟣 紫 | 4（数のはんい 1〜100 に拡大） |
| 公約数 | 🟠 オレンジ | 5 |

未習得のカテゴリは図鑑上で 🔒 グレー表示され、フェーズが進むと解禁されます。

## ファイル構成

```
src/
├── appsscript.json   … GAS マニフェスト
├── Code.gs           … サーバーサイド（配信・スプレッドシート読み書き）
├── index.html        … 画面の HTML（全画面を1ページに内包）
├── styles.html       … CSS（名探偵テーマ）
└── app.html          … フロントエンドの JavaScript（ゲームロジック一式）
```

`index.html` は GAS の `include()` で `styles` / `app` を読み込みます。

## デプロイ手順

### 方法A：Google Apps Script エディタに手貼り

1. [script.google.com](https://script.google.com) で新規プロジェクトを作成。
2. `src/Code.gs` の中身を `コード.gs` に貼り付け。
3. `＋` →「HTML」で `index` / `styles` / `app` の3ファイルを作り、
   それぞれ `src/index.html` / `src/styles.html` / `src/app.html` の中身を貼り付け
   （ファイル名は拡張子なしで `index`・`styles`・`app`）。
4. マニフェスト（`appsscript.json`）を表示する設定を ON にし、`src/appsscript.json` の内容に合わせる。
5. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**組織内の全員**（`appsscript.json` の `access` は運用に合わせて調整）
6. 発行された URL を児童に配布。

### 方法B：clasp（コマンドライン）

```bash
npm install -g @google/clasp
clasp login
clasp create --type webapp --title "名探偵かずのひみつ" --rootDir ./src
clasp push
clasp deploy
```

> `.clasp.json` の `rootDir` を `./src` に向けると、`src/` 配下の
> `.gs` / `.html` / `appsscript.json` がそのままアップロードされます。

### スプレッドシートについて

- 初回アクセス時に、必要なシート（`problems` / `group_scores` / `progress` / `config`）が
  **自動で作成**されます（手動セットアップ不要）。任意で `setup()` を実行しても構いません。
- スタンドアロン運用の場合は専用スプレッドシートが自動生成され、その ID が
  スクリプトプロパティ `SPREADSHEET_ID` に保存されます。
- コンテナバインド（スプレッドシートに紐づけて作成）した場合は、そのシートが使われます。

### データ構造

| シート | 列 |
|--------|----|
| `problems` | id, secret, range, hints_json, author, candidates, created_at |
| `group_scores` | id, session, group_name, score, hints_used, time_sec, created_at |
| `progress` | student, unlocked_json, badges, rank, updated_at |
| `config` | key, value（`phase`：現在の単元フェーズ、`groupSession`：対抗戦のセッション名） |

## 教員向け：単元フェーズの切替

ホーム画面 →「せんせい設定」から、現在の単元フェーズ（1〜6）を選ぶだけで、
**使えるヒントの種類**と**数のはんい（50 / 100）**が児童全員の画面に反映されます
（設定は `config` シートに保存されます）。

| フェーズ | 単元 | はんい | 使えるヒント |
|---------|------|-------|------------|
| 1 | 偶数・奇数 | 1〜50 | 偶数・奇数 |
| 2 | 倍数 | 1〜50 | ＋倍数 |
| 3 | 約数 | 1〜50 | ＋約数 |
| 4 | 公倍数 | 1〜100 | ＋公倍数（LEVEL UP 演出） |
| 5 | 公約数 | 1〜100 | ＋公約数 |
| 6 | 名探偵認定 | 1〜100 | 全部混合＋認定試験 |

## スコア計算式（グループ対抗）

`app.html` の `Group.computeScore(timeSec, hintsUsed)` にまとめてあり、後から調整できます。

```
スコア = max(10, 100 + speedBonus - hintPenalty)
  speedBonus  = max(0, 60 - かかった秒数)   // 速いほど加点
  hintPenalty = 使ったヒント数 × 8           // ヒントが少ないほど高得点
```

## 開発メモ

- ゲームのヒント生成・数の性質判定は `app.html` の `Engine` にまとまっています。
- GAS 通信は `Server.call()` に集約。GAS 以外の環境（ローカルプレビュー等）では
  自動的に `localStorage` にフォールバックするため、ブラウザ単体でも動作確認できます。
