## 3. 目指すスタイル（参考動画の分析）

参考：「1分でわかる日本史 第一回・本能寺の変」（ユーザー提供の13秒クリップから分析）

**構成の型**

| 秒 | 演出 |
|---|---|
| 0–1.5 | 背景（金屏風）＋中央から光が広がる＝タメ |
| 1.5–2.6 | ロゴが**ドンと着地**（縮みながら出現）＋サブコピー |
| 2.6–3.4 | 小見出し「第一回 ◯◯」、ロゴをゆっくりズーム |
| 3.8–5.6 | **巨大な明朝体タイトル**＋赤影、下に一行の煽り |
| 6.4 | 立ち絵＋名前プレート、関係ラベルを線でつなぐ |
| 7.2 | 関係が**赤い亀裂で割れる**＋極太赤文字＋「※」注釈 |
| 9.4 | 黒地に**巨大な金の数字**＋下部にタイムライン |
| 10.6–13 | **地図に色が広がる**＋**％カウントアップの進捗バー**＋注釈 |

**貫かれている設計**
- 画面下に**ナレーション字幕バーが常時**
- **黒 × 金 × 赤**（＋白）／**極太の日本語タイポ**
- **数字・％・バー・地図**で情報を絵にする
- 小さな「※」注釈でテンポと親しみを出す
- 「1分でわかる」という**冠フォーマット**で先に期待値をつくる

→ 本アプリの配色（セピア×金×赤）と相性が良いので、そのまま応用できる。

> **参考動画は今も視聴できていない**（原因は特定済み・下記）。
> v4 の構成は、この13秒分の分析だけをもとに組んである。

### なぜ YouTube が見られないのか（調査済み・再調査不要）

環境の **ネットワークアクセスが `Trusted`（＝許可リスト方式）** のため。
YouTube だけでなく google.com も wikipedia.org も等しく拒否され、
GitHub・npm・PyPI・`*.googleapis.com` は通る、という切り分け結果だった。

```
connect_rejected  www.youtube.com:443   gateway answered 403 to CONNECT
connect_rejected  www.google.com:443    gateway answered 403 to CONNECT
```

WebFetch も同じプロキシを通るので同様に 403 になる。

**解除するには**：環境設定 → Network access を `Custom` にし、
「既定のパッケージマネージャ一覧も含める」を有効にしたうえで
`youtube.com` / `*.youtube.com` / `youtu.be` / `*.ytimg.com` /
**`*.googlevideo.com`**（映像の実体はここから配信されるので必須）を追加する。
設定はセッション開始時に読まれるため、**変更後は新しいセッションが必要**。
`yt-dlp` は PyPI 経由で入る。

いちばん早いのは、**動画ファイルを直接セッションにアップロードしてもらう**こと。

## 4. 音まわりの調査結果

- **クラウドTTS（edge-tts等）は使えない**（外部ドメインが遮断される環境の場合）
- **オフライン音声合成は使える**：`pip install pyopenjtalk soundfile`
  ```python
  import pyopenjtalk, soundfile as sf
  x, sr = pyopenjtalk.tts("読み上げたい文章")
  sf.write("out.wav", (x/32768.0).astype("float32"), sr)
  ```
  - 声は **Mei（女性）1種類のみ**。明瞭だが**やや機械音声**。ユーザーの可否判断待ち。
- **効果音は合成で自作可能**（時計のカチカチ／スタンプの「ドン」／正解音）。著作権の心配なし。
- **BGMは既製音源が必要**（ユーザーから提供してもらう）。

## 5. ハマりどころ（同じ失敗を繰り返さないために）

### フォントが代替表示になる
`fonts.googleapis.com` はネットワーク的には許可されていても、
サンドボックス内のChromiumからは取得に失敗した（`ERR_CONNECTION_RESET`）。
→ **対策：フォントを `curl` で先にダウンロードし、`@font-face` でローカル埋め込みしてから録画する。**
（本番のGASアプリでは正常に表示されるので、アプリ側の修正は不要）

> **真因が判明**：ドメイン遮断ではなく、**Chromium が `HTTPS_PROXY` を読まない**ため。
> curl では普通に取得できる。対策自体は上記のままで正しい。
> 取得は `tools/video/remotion/scripts/fetch-fonts.py` に実装済み（489サブセット・約9.6MB）。

### 画面録画（recorder2.py）での注意
1. **セレクタの重複**：`.page-head .back` は6個、`.case-paper` は12個ある。
   → `.screen.active .page-head .back` のように**アクティブ画面に限定**する。
2. **ズーム中のクリックは空振りする**：ズームのトランジション中に座標を測ると外れる。
   → `zin()` は `dur + settle` だけ待つ。`click()` は**カーソル移動後に座標を再計測**してから押す。
3. **画面外の要素は押せない**：グリッドにズームしていると下の「手がかりを調べる」ボタンが画面外。
   → `click()` に**画面外なら自動でズームを戻すガード**を入れてある。
4. **タップの取りこぼし**：`tap_matching()` は未タップのマスを**最大3回まで自動で回収**する。
5. **モーダルはズームと相性が悪い**：アプリのモーダルは `position:fixed` なので、
   ズーム中に開くと画面外に飛ぶ。→ **モーダルが出る前に `zout()` し、開いてから改めてズーム**する。
6. **ランクアップが割り込む**：解決モーダルの0.5秒後に昇格モーダルが上書きされる。
   → バッジ数を調整して**意図した方だけ出す**（例：解決だけ見せたい時は閾値をまたがない値にする）。

### レンダリング
- 静止画ベースの合成なら、**同一フレームはハードリンクで複製**すると2〜3倍速くなる
  （`render_fast.py` 方式：`window.__key()` で状態ハッシュを取り、変化がなければ複製）。
- 実写録画は Playwright の `record_video_dir` を使う（webm出力 → ffmpegでmp4化）。

## 6. ファイル

| ファイル | 役割 |
|---|---|
| `DESIGN.md` | **v4 の絵づくり仕様と90秒の絵コンテ**（まずこれを読む） |
| `director.js` | 録画用オーバーレイをページに注入する（v4 ではズーム／カーソル／波紋／リングだけ使う） |
| `recorder_v4.py` | **v4 の収録スクリプト**。カットごとに mp4 を書き出す |
| `recorder2.py` | v3 の収録スクリプト（テロップ焼き込み版・参考用に残置） |
| `diagnose_interactions.py` | クリックやゲーム進行がうまくいかない時の切り分け用（動画なしで高速に検証） |
| `remotion/` | v4 の編集プロジェクト。`src/Main.tsx` が90秒の本編 |

> v4 では **テロップ類を録画に焼き込まない**。director.js はズームとカーソルだけ担当し、
> テロップ・証拠カード・カウンタ・スタンプは Remotion 側で合成する。
> 理由と対応表は DESIGN.md §5。

### 使い方
```bash
pip install playwright imageio-ffmpeg
# アプリの単体プレビューHTMLを生成（src/ から結合）
node -e '...'   # recorder2.py 内のパスに合わせて preview.html を用意する
python3 recorder2.py            # 録画（webm）
# webm -> mp4
ffmpeg -i video2/*.webm -c:v libx264 -pix_fmt yuv420p -crf 21 -r 30 out.mp4
```

> Chromium は `/opt/pw-browsers/` に同梱されているものを使う想定
> （`executable_path` を環境に合わせて直すこと）。

## 7. 次のセッションでの進め方（おすすめ）

1. **`DESIGN.md` を読む**（絵づくりと90秒の絵コンテはそこで確定済み）
2. 画面比率とナレーションの扱いをユーザーに確認
3. `recorder2.py` から**テロップ注入を外して**素材を撮り直す
   （DESIGN.md §4 の「素材＝録画」の行が必要なカット。フォント埋め込みを忘れずに）
4. Remotion で絵コンテどおりに 90秒へ組む（部品は `remotion/src/components/` に実装済み）
5. **確認役に検品させる** → 合格したら納品

```bash
cd tools/video/remotion
python3 scripts/fetch-fonts.py            # 初回のみ（woff2 は git 管理外）
npm install
cd ../../.. && python3 tools/video/recorder_v4.py   # 素材を撮る（git 管理外）
cd tools/video/remotion
npm run stills                            # キーフレームで絵を確認
npm run render                            # 90秒の本編を out/main.mp4 に書き出す
```

> フォントと画面録画は容量が大きいので git に入れていない。
> どちらもスクリプトで決定論的に作り直せる。
